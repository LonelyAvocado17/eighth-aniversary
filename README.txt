OUR.EXE — Eight Months of Us
================================

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Click START COMPUTER.

HOW TO PERSONALISE
Open index.html in a text editor (VS Code is recommended).
Find the CONFIG object near the beginning of the JavaScript section.
Replace the sample text with your own details.

IMAGES
- Put chat screenshots in assets/screenshots/
- Put photos in assets/photos/
- In CONFIG.screenshots, update each file path.
- In CONFIG.memories, set image to e.g. "assets/photos/month-01.jpg"

PERSONAL CONTENT
Edit:
- girlfriendName
- reasons (five specific reasons)
- memories (eight month entries)
- screenshots (file, title, caption)
- insideJokes
- playlist
- notes
- letter
- finalMessage
- cosmicStars (eight star memories)

NOTES
- The website is self-contained; no build tools or packages are needed.
- It works locally by opening index.html.
- For sharing online, upload the extracted folder to GitHub Pages, Netlify, or another static host.
- Audio is not autoplayed. Add song links to CONFIG.playlist.
- The Paint app lets her draw and download a PNG.
- On touch screens, tap desktop icons twice to open them.
